# 桃花之源

一个零依赖的极简发布页：写下此刻的想法，它会以卡片形式留在时间线上，刷新或关闭页面都不会丢失。

## 功能

- **发布内容**：顶部输入框支持多行输入，右上角实时显示字数（上限 280），内容为空时发布按钮不可用。
- **时间线查看**：新发布的内容置顶展示，卡片底部显示相对时间（刚刚 / 5 分钟前 / 3 天前 / 具体日期）。
- **本地持久化**：所有内容保存在浏览器 `localStorage` 中，不经过任何服务器。
- **空状态引导**：还没有内容时展示引导文案。
- **响应式**：移动端单列铺满，桌面端限制 640px 阅读宽度居中。

## 技术

纯 HTML5 + CSS3 + 原生 JavaScript（ES6+），无框架、无构建工具、无 npm 依赖、无后端请求。

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面语义骨架 |
| `style.css` | 桃花主题样式与动效 |
| `app.js` | 本地存储读写、发布、时间线渲染 |

## 运行

直接双击 `index.html` 即可使用；也可以用任意静态服务器打开：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 数据说明

数据存放在当前浏览器的 `localStorage`，键名为 `taohua:posts`，值为如下结构的数组：

```json
[{ "id": "uuid", "content": "内容", "createdAt": 1730000000000 }]
```

内容仅存在于本机浏览器：换浏览器、换设备、清理浏览器数据都会导致内容消失。
